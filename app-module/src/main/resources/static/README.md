# UI статики app-module

Одностраничная консоль LoadTest (без сборщика): HTML + CSS + набор JS-файлов с общим глобальным scope (порядок подключения в `index.html` важен).

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка вкладок (очередь, история, запуск, конфигурация) |
| `css/app.css` | Темы light/dark, компоненты, таблицы, формы |
| `js/state.js` | API base URL, константы, тема, кеш страниц |
| `js/dom.js` | escapeHtml/escapeAttr, разбор summaryData |
| `js/metrics.js` | Редактор metricsConfig |
| `js/summarizers.js` | Справочник маршрутов LLM, бейджи, форма маршрута |
| `js/navigation.js` | Вкладки, профили Docker для запуска |
| `js/queue.js` | Очередь задач и пауза |
| `js/history.js` | История, детальная карточка, суммаризация |
| `js/utils.js` | formatDate, пагинация (обработчики) |
| `js/run.js` | Форма запуска: инструменты и маршруты |
| `js/config.js` | CRUD инструментов и маршрутов |
| `js/init.js` | Docker-профили, submit запуска, стартовая загрузка |

## Как открывать

- **Рекомендуется:** запустить `app-module` и открыть `http://localhost:8080/` — CSS, JS и API с одного origin.
- **Файлом:** можно открыть `static/index.html` в браузере (пути к `css/` и `js/` относительные). Данные с API всё равно идут на `http://localhost:8080` — бэкенд должен быть запущен.

Не используйте пути вида `/css/app.css` при открытии через `file://` — браузер ищет их на диске в корне диска, стили не подгрузятся.
